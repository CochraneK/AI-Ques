# P001 · Self Concept / Future Self Continuity

P001 是 P00 Lab 的自我概念交互原型，当前 GitHub Pages 版本同步自本地 **v5 Beta 5.2**。

## 当前流程

1. **现在的我**：N/E/O/A/C 共 30 facet，随机逐张左右滑筛选；桌面支持 ← / →，↑ 返回。
2. **现在的我 STJ**：守擂式 paired comparison，赢家留场，输家滑走并补新卡；支持 ← / → 和 ↑ 撤回。
3. **理想的我**：E/O/A/C 共 24 facet；默认不呈现 N 维负向候选。
4. **理想的我 STJ**：同样使用守擂式比较。
5. **我最看重什么**：16 张个人价值卡逐张滑选并排序；价值分类仅用于界面组织，不冒充正式量表维度。
6. **未来自我距离**：独立 distance slider。
7. **未来自我重叠**：独立圆形 overlap 游戏。
8. **未来一天 / 障碍 / 行动**：以点选为主。
9. **两句话**：仅保留“送给未来自己的话”和“希望未来的自己送给现在的话”两处自由表达。
10. **分享海报**：从完整报告中单独生成适合保存的视觉卡。

## GitHub Pages 与本地研究版

`/p001/` 是可直接体验的静态原型。由于 GitHub Pages 没有 Python 后端，本目录使用 `static-api.js` 将身份、event 与 result 暂存在当前浏览器 `localStorage`。它只用于产品/交互演示，**不构成正式研究的数据治理或管理员权限实现**。

正式本地研究版继续使用 Python 后端、身份/activity DB 分离、管理员导出与完整事件记录。

## 科学边界

- 30 facet 趣味层是 source-grounded 的自我反思层，不等同于 IPIP-NEO-120 标准计分。
- 理想自我层主动排除 N 维负向候选，因此不是完整 30-facet 结构测量。
- STJ 是个体内优先级，不应解释为 normative Big Five 分数。
- Personal Values 是独立构念，不属于“现在的我 / 理想的我 / 未来的我”的人格分数。
- Future Self 距离与重叠是两个独立连续变量。

正式收数前仍需冻结正式量表版本、知情同意、伦理、数据治理、退出与风险处置流程。

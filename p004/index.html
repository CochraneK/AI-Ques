P004 DESIGN

聊天，不是变形的量表。

P004 将“对话体验”和“研究观察”拆成两条链路：聊天 Agent 负责自然交流；Observer 只读会话并输出带不确定性的结构化证据。

Conversation→Evidence→Observer→Profile

当前 GitHub Pages 版本默认使用本地启发式 demo。生产版建议把 LLM 调用放到后端代理，并分别配置 conversation / observer / safety 三个职责。
